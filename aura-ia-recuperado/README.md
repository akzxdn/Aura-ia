# AURA IA

Projeto reconstruído a partir das alterações preservadas no compartilhamento do Codex.

## Executar

1. Instale as dependências com `npm install`.
2. Copie `.env.example` para `.env.local` e adicione sua chave apenas localmente.
3. Execute `npm run dev`.

O modo demonstração funciona sem chave. Nunca envie `.env.local` ao GitHub.
